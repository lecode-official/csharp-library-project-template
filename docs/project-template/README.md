# Project Template

This section covers the repository as a Copier template: how it is laid out, what it asks, how the `LICENSE` file is produced, what a consumer does with it, and how a change to the template body is made and verified.

1. [Template Structure](template-structure.md) — the two-level layout, and the four problems it solves.
2. [Questions](questions.md) — every question, what it feeds, and how to add one.
3. [Licensing](licensing.md) — how the `LICENSE` file is produced, and which licenses take a copyright substitution.
4. [Rendering and Updating](rendering-and-updating.md) — generating a project, and keeping it in step with the template.
5. [Authoring](authoring.md) — the delimiters, adding a file, and verifying a change.

Start with [template structure](template-structure.md) if you have not worked on this repository before. The split between the root and `template/` is the thing that makes everything else make sense, including the [conventions](../conventions/README.md) and the [tooling](../tooling/README.md), which both apply differently to each side.
