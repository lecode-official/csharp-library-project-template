# Development Setup

This section covers everything to install and set up before working on the template: the tools, the repository on GitHub, and the editor.

1. [Installing the Tools](installing-the-tools.md)
2. [Setting up GitHub](setting-up-github.md)
3. [Setting up Visual Studio Code](setting-up-visual-studio-code.md)

Working on the template's own files needs only Git and Node.js. Verifying a change to the template body by rendering it needs Copier and the generated project's toolchain on top. Setting up GitHub is only needed once, for a new repository, and Visual Studio Code is optional.
