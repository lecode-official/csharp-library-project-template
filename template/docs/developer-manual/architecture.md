# Architecture

This article covers how the repository is laid out.

## Repository Layout

The repository is organized into a few top-level directories:

- [`docs/`](../README.md) — this documentation.

Top-level files round out the repository. [`README.md`](../../README.md) is the project's front door, [`CHANGELOG.md`](../../CHANGELOG.md) records what changed in each version, [`CONTRIBUTORS.md`](../../CONTRIBUTORS.md) lists everyone who has contributed, and [`LICENSE`](../../LICENSE) is the full text of the license. [`CONTRIBUTING.md`](../../CONTRIBUTING.md), [`CODE_OF_CONDUCT.md`](../../CODE_OF_CONDUCT.md) and [`SECURITY.md`](../../SECURITY.md) round out the community-facing files a repository host recognizes by name.

## Versioning and Licensing

[`CHANGELOG.md`](../../CHANGELOG.md) is the human-readable history of what each version changed. It is not generated from Git history, so it is updated by hand.

The project is licensed under `[[ license ]]`, and [`LICENSE`](../../LICENSE) carries the full text of the license.
