# Design Assets

Logo and brand assets for [[ product_name ]]. Usage, rationale, and the dos and don'ts are documented in the [logo design](../docs/developer-manual/logo-design.md) guide — this folder only holds the files.

This directory is the source of truth for the **vector masters**. The copies that the read me, the documentation website, and the package reference live in [`docs/assets/`](../docs/assets/README.md) instead. Nothing regenerates the copies automatically. Update them by hand whenever a master changes, and commit both.

The files below are the placeholder logo every project starts with, an open book with the name of its language on the pages. Replace them with the project's own logo (see the [logo design](../docs/developer-manual/logo-design.md) guide).

## Mark

- `mark-light.svg` / `mark-dark.svg` — the mark on its own, for light and dark backgrounds. The read me header and the favicon are made from it.

## Badge

- `badge-light.svg` / `badge-dark.svg` — the mark on a rounded square, for the header of the documentation website and the package icon.
